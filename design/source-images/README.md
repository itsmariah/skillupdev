# Imagens originais

Arquivos-fonte em alta resolução das imagens do site. O site não usa estes arquivos:
ele carrega as versões otimizadas (WebP, no dobro do tamanho exibido) em
`frontend/assets/images/`.

Ao trocar uma imagem, gere a versão otimizada a partir daqui e mantenha o original nesta pasta.
